# Presentation design pass

Audience: an academic project presentation of diabetic retinopathy screening and 15 biomedical tutorials.

Palette: ink #172e45, clinical teal #087d78, slate #677b8d, paper #f3f6f9, divider #e0e7ed, white #ffffff.
Typography: Aptos / Segoe UI with a 37px result/preview heading, 30px page title, 19px input title and 13-14px supporting text. Labels stay sentence case.
Layout: a restrained brand header, subject navigation, compact image input at left and a larger evidence workspace at right. A real retinal sample provides the focal point before analysis; measured severity, confidence and quality become the focal point afterward. Left-aligned text supports live narration.
Review: removed the generic gradient banner, duplicate numbered tab strip, empty probability placeholder and saturated label backgrounds. Replaced them with retinal imagery, grouped navigation and result hierarchy specific to this application. Tutorial IDs remain visible inside tutorials because these identify actual coursework.
Accessibility: keyboard focus, reduced-motion rules, readable colors and mobile layout. No new animations or external font downloads.

Installed 15 related skills: frontend-design, webapp-testing, web-artifacts-builder, theme-factory, figma, figma-code-connect-components, figma-create-design-system-rules, figma-create-new-file, figma-generate-design, figma-generate-library, figma-implement-design, figma-use, playwright, playwright-interactive, screenshot. Product Design, Figma and MagicPath plugin installation/connection requires the application's user-controlled connection flow; these are not confirmed installed.
